# Домашка к ролику 5: идея -> продажи по порядку

Файлы к ролику про SEO-сервис, код которого целиком написал Claude: 759 коммитов из 759, а за полгода — всего $510 (плейлист «Свои продукты с AI»). Код дался легко, продажи — нет.
Примеры вымышленные, суммы в долларах.

Задание — то же, что в конце ролика. Я сделал наоборот, а ты сделай по порядку:

1. Назови трёх людей, которые заплатят за твою идею.
2. Спроси их.
3. Доведи идею до дерева задач.
4. Запиши стоп-цифру: сколько времени и денег, после которых бросаешь.

## Что внутри
- `checklist.md` — шесть шагов ролика (идея, задачи, код, прод, деньги, продажи) и домашка.
- `spec-template.md` — шаблон одностраничного ТЗ: три человека, их ответы и стоп-цифра.
- `decomposition-prompt.md` — промпт: ТЗ -> дерево задач для Claude Code.
- `CLAUDE.md.example` — пример `CLAUDE.md` как индекса.
- `review-checklist.md` — как принимать работу Claude.

## Порядок
1. Назови трёх человек и спроси их. Ответы запиши в `spec-template.md`.
2. Заполни ТЗ, внизу — стоп-цифру.
3. Прогони `decomposition-prompt.md`, получи `BACKLOG.md`.
4. Положи `CLAUDE.md.example` в проект как `CLAUDE.md` и заполни.
5. Задачи отдавай по одной, принимай по `review-checklist.md`.
6. Дошёл до стоп-цифры без продаж — остановись и признай. Это тоже результат.
