# Приёмка работы Claude

Проходи после каждой задачи, до того как отметить её сделанной.

## Запускается ли
- [ ] Проверочная команда из `CLAUDE.md` проходит
- [ ] Страницу или команду открыл сам и увидел результат глазами

## Соответствует ли задаче
- [ ] Критерий готовности из `BACKLOG.md` выполнен буквально
- [ ] Тронуты только файлы, названные в задаче
- [ ] Нет «заодно» добавленных функций

## Не сломано ли старое
- [ ] Прежние проверки зелёные
- [ ] Для исправленной ошибки есть проверка, которая падала до исправления

## Безопасность и деньги
- [ ] В коде и коммите нет ключей, паролей, адресов с доступом
- [ ] Внешние вызовы с лимитом и таймаутом
- [ ] Ошибки не глотаются молча

## Если сомневаешься
Попроси Claude объяснить изменение по файлам, потом сам открой дифф. Отметка «сделано» без проверки не считается.
