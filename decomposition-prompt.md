# Промпт: идея -> дерево задач для Claude Code

Вставь в Claude Code, подставь свои значения в `<...>`. Приложи заполненный `spec-template.md`.

```
Вот ТЗ на продукт: <вставь spec-template.md>.

Разбей его на дерево задач. Правила:
1. Каждая задача делается за один заход и проверяется одной командой или одним действием в браузере.
2. У каждой задачи: название, какие файлы трогает, критерий готовности, от каких задач зависит.
3. Первая задача даёт работающий скелет, который можно запустить. Остальные его наращивают.
4. Не больше 3 уровней вложенности. Задача длиннее одного экрана текста делится дальше.
5. Не придумывай то, чего нет в ТЗ. Если не хватает решения, выпиши вопрос отдельным списком в конце.

Выведи: дерево в виде маркированного списка, затем порядок выполнения, затем вопросы.
Сохрани результат в BACKLOG.md.
```

## Как пользоваться результатом
- Отдавай Claude по одной задаче: «Сделай задачу 1.2 из BACKLOG.md».
- После каждой задачи проходи `review-checklist.md`.
- Отметил задачу сделанной только после проверки.
